## What is Locaible?

Locaible is a desktop app (Windows, macOS, Linux) that lets you build and run **AI agents that run entirely on your machine**. No data is sent to the cloud. The local LLM engine (Ollama) is installed and managed for you — no terminal, no configuration.

Use cases:
- Confidential document Q&A (legal, medical, HR) without ever uploading the document
- A private ChatGPT that knows your codebase, your notes, your company docs
- Team-shared agents with end-to-end encryption (seats)
- Marketplace of community-built agents you can install in one click

## Features

- 🔒 **100% local AI** — Ollama set up automatically
- 🗂️ **Local RAG** — index your PDFs, DOCX, MD, TXT files
- 🔌 **Connectors** — Notion (more coming), with OS-keyring secret storage
- 👥 **Team seats** — share agents with end-to-end encryption
- 🌍 **Multi-platform** — Windows · macOS · Linux
- 🆓 **Free to start**

## Why this repo is public

The Locaible source code lives in a private repository. This public repo hosts the **release installers only**, so anyone can download the desktop app without a GitHub account.
